# Trafic Péi

Trafic en direct, radars fixes et alertes de zones de danger à La Réunion.

- **Trafic en direct** : carte officielle Waze intégrable (bouchons, accidents, travaux signalés par les conducteurs).
- **Radars & conduite** : radars fixes issus d'OpenStreetMap, et mode conduite avec annonce vocale des zones de danger
  (300 m en ville, 2 km sur route, 4 km sur voie rapide), conforme à l'interdiction de signaler l'emplacement précis des radars.

Aucune clé ni compte nécessaire. Hébergé sur GitHub Pages ; installable sur l'écran d'accueil (iPhone : Partager → Sur l'écran d'accueil).

Données : © contributeurs OpenStreetMap · carte trafic © Waze.
